# learnings/

팀으로 올리기 **전** 또는 skill/rule로 아직 안 굳은 메모를 둔다.

권장 형식 (파일명 예: `2026-09-11-topic.md`):

```markdown
# <짧은 제목>

- Date: YYYY-MM-DD
- From: <앱 레포>/plans/.../progress-log.md
- Status: draft | candidate | promoted → skills/<name>

## Fact / decision

(민감정보 없이)

## Repro / when it matters

## Do not promote if

(일회성·환경특수·민감)
```

승격 절차: `skills/promote-learning/SKILL.md`.
promoted 후 이 파일은 삭제하거나 `Status: promoted`만 남긴다.
