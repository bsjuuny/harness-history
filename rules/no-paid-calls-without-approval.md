# 유료 호출은 승인 없이 하지 않는다

모든 AI 에이전트(Claude · Codex · Grok · 기타) 공통.

사용자가 그 실행을 **명시적으로 승인하지 않았다면** 비용이 드는 호출을 하지 않는다.

- 대상: 쓴 만큼 과금되는 API(LLM API 키 호출, 유료 외부 API, 클라우드 리소스 생성 등),
  그리고 그런 호출을 하는 스크립트·파이프라인 실행(재현·e2e·"한 번 돌려보기" 포함).
- "원인 파악해줘", "확인해줘", "고쳐줘"는 **진단·수정 요청이지 유료 실행 승인이 아니다.**
- 이미 예약된 정기 실행(스케줄러 등)은 사용자가 정한 운영이라 이 규칙의 대상이 아니다.
  그 실행을 에이전트가 **대신 추가로 돌리는 것**은 대상이다.

먼저 무료로 한다:

1. 코드 읽기, 기존 로그·상태 파일, 이전에 저장된 응답.
2. 외부 호출을 mock 한 단위테스트로 수정 검증.
3. 정보가 부족하면 **로그를 보강해 다음 정기 실행 결과를 기다린다** — 대기 시간을 줄이려고
   유료 호출을 쓰지 않는다.

유료 실행이 꼭 필요하면:

- 무엇을, 몇 회, 대략 어느 정도 규모(호출 수·토큰)인지 말하고 승인을 받는다.
- 승인된 횟수만 실행하고, 응답은 파일로 저장해 이후 분석은 추가 호출 없이 한다.
- 승인은 그 실행에만 유효하다. 다음 실행은 다시 묻는다.

Source: 워크스페이스 운영 사례 (2026-10-23) — 원인 파악 중 에이전트가 승인 없이 LLM API
파이프라인을 반복 실행해 크레딧을 소진하고 정기 실행까지 막힌 일. 결정적 원인은 코드·로그만으로
찾을 수 있었다.
